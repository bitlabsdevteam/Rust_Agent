# SOULD

This file captures high-signal local guidance for what the workspace
agent should do by default. The filename is intentionally `SOULD.md`
to match the requested workspace artifact.

## Default Behavior

- should start from a clear task contract
- should prefer repo-local documents over chat-only memory
- should keep tool and skill use explicit and traceable
- should retry only recoverable failures
- should stop instead of looping when no new information appears
- should leave a clear final answer and usable execution trace

## Documentation Standard

- keep notes short, stable, and actionable
- update this file only for durable workspace guidance
- move detailed design material into versioned docs when the project grows
